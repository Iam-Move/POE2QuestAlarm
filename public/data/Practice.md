# POE2 Quest Navigator 사용 안내

POE2 퀘스트 알리미는 Path of Exile 2의 퀘스트 진행 현황을 빠르게 추적할 수 있는 도구입니다.

---

## 필터 모드

상단의 버튼으로 플레이 스타일에 맞는 필터를 선택하세요.

- **Regular** — 일반 진행용 퀘스트 목록
- **Semi-Strict** — 중간 난이도 최적화 목록
- **Uber** — 우버 엔드게임 최적화 목록
- **Custom** — 직접 선택한 퀘스트만 표시 (아래 설명 참고)
- **사용자 추가 필터** — 공유 링크 합치기로 추가된 필터, 또는 직접 만든 필터

> **편집 모드에서 필터 탭 관리**
> - 필터 이름을 **더블클릭**하면 이름을 변경할 수 있습니다
> - 필터 이름 옆의 **×** 버튼을 클릭하면 해당 필터 탭을 숨깁니다 (데이터는 유지)
> - **[+ 필터 추가]** 버튼으로 나만의 새 커스텀 필터를 만들 수 있습니다

---

## 퀘스트 완료 체크

퀘스트 항목을 클릭하면 완료/미완료가 토글됩니다. 완료된 퀘스트는 시각적으로 구분되며, 상단 진행률 바에 자동 반영됩니다.

---

## Custom 필터 사용법

나만의 퀘스트 목록을 만들고 싶을 때 사용합니다.

1. **편집 모드** 버튼을 켭니다
2. 원하는 퀘스트 옆의 **체크박스**를 클릭해 현재 필터 목록에 추가합니다
3. **필터를 Custom으로 전환**하면 체크 표시한 퀘스트만 표시됩니다

직접 만든 추가 필터도 동일하게 동작합니다.

---

## 편집 모드

오른쪽 상단의 **편집 모드** 버튼을 켜면 추가 기능이 활성화됩니다.

- **퀘스트 수정** — 이름, 보상, 메모를 직접 편집
- **퀘스트 추가** — 각 퀘스트 사이에 나타나는 **+ 여기에 추가** 버튼으로 원하는 위치에 바로 삽입
- **퀘스트 삭제** — 삭제 버튼으로 목록에서 제거
- **순서 변경** — 드래그 앤 드롭으로 퀘스트 순서 조정
- **필터 설정** — 각 퀘스트가 어느 필터에 포함될지 개별 지정
- **필터 이름 변경** — 필터 탭을 더블클릭하여 이름 변경
- **필터 추가** — 필터 바 끝의 [+ 필터 추가] 버튼으로 새 커스텀 필터 생성
- **필터 숨기기** — 필터 탭 옆 × 버튼으로 탭 숨기기 (데이터는 유지)

---

## 오버레이 모드 (PIP)

게임 화면 위에 퀘스트 목록을 띄울 수 있습니다.

- **오버레이** 버튼을 클릭하면 별도의 작은 창이 열립니다
- Picture-in-Picture 기술을 사용해 다른 창 위에 항상 표시됩니다
- 브라우저가 PIP를 지원하는 경우에만 버튼이 표시됩니다 (Chrome 권장)

---

## 공유

내 퀘스트 설정 전체를 다른 사람과 공유할 수 있습니다.

- **공유** 버튼을 클릭하면 현재 상태가 담긴 URL이 클립보드에 복사됩니다
- 해당 URL을 열면 공유된 설정을 불러올지 묻는 알림이 표시됩니다
- 필터 설정, 커스텀 별표, **직접 추가/수정한 퀘스트**까지 포함됩니다
- 완료 체크는 공유되지 않으며, 받는 사람이 자신의 진행 상황에 맞게 따로 체크할 수 있습니다

### 필터 추가하기

공유 링크를 열면 **필터 추가하기** 버튼으로 설정을 가져올 수 있습니다.

- 공유된 커스텀 필터와 퀘스트가 내 설정에 추가됩니다. 기존 필터와 퀘스트는 유지됩니다.

예를 들어 유튜버 3명이 각자의 퀘스트 세트를 공유 링크로 배포했다면, 링크 3개를 차례로 **필터 추가하기** 하면 필터 탭 3개가 공존하게 됩니다.

> **참고 — 공유 링크는 실시간 동기화가 아닙니다**
>
> 공유 링크는 버튼을 누른 **그 순간의 상태**를 저장한 스냅샷입니다.
> 이후에 퀘스트를 추가하거나 수정·삭제해도 이전에 공유한 링크에는 반영되지 않습니다.
> 변경 사항을 상대방과 공유하려면 **공유 버튼을 다시 눌러** 새 링크를 전달해야 합니다.

## 데이터 관리 (CSV)

상단의 **데이터** 버튼을 클릭하면 CSV 형식으로 퀘스트를 관리할 수 있습니다.

### CSV 내보내기 (백업)
- **현재 선택된 필터**의 퀘스트를 `.csv` 파일로 저장합니다
- 완료 체크와 필터별 포함 여부도 함께 저장됩니다
- 브라우저 데이터가 초기화되어도 이 파일로 복원할 수 있습니다
- 중요한 진행 상황은 주기적으로 내보내 두는 것을 권장합니다

### CSV 가져오기 (복원 / 목록 추가)
- CSV 파일을 업로드하면 가져오기 옵션이 표시됩니다
  - **목록만 가져오기** — 퀘스트 목록만 추가, 완료 체크는 무시 (크리에이터 목록 가져올 때)
  - **진행상황 포함 가져오기** — 완료 체크까지 복원 (내 백업 파일 복원 시)
- CSV의 필터 컬럼 이름이 기존 필터 탭과 일치하면 자동 연결되고, 없으면 **새 필터 탭을 자동 생성**합니다

### CSV 형식

내보내기/양식의 컬럼 구성:

| 컬럼 | 설명 |
|------|------|
| `act` | act1 ~ act6 형식 (필수) |
| `Quest` | 퀘스트 이름 (필수) |
| `Reward` | 보상 (선택) |
| `Note` | 메모 (선택) |
| `[필터명]` | 필터 탭 이름 컬럼. **한글 이름도 사용 가능**하며, 필터 탭 이름을 바꾸면 컬럼명도 함께 바뀝니다 |
| `Completed` | 완료 여부 (`true` / `false`) |

> **Google Sheets에서 체크박스로 표시하기**
>
> 필터 컬럼을 선택 → **데이터 → 데이터 유효성 검사 → 체크박스** 선택
> 셀이 체크박스 형태로 표시되며, CSV로 내보낼 때 `TRUE`/`FALSE`로 저장됩니다.
> 가져오기 시 대소문자 구분 없이 자동 인식됩니다.

### 빈 양식 다운로드
- Google Sheets / Excel에서 바로 작성할 수 있는 CSV 양식을 다운로드합니다
- 현재 사용 중인 필터 탭 이름이 컬럼으로 포함됩니다
- 양식을 채운 후 CSV 가져오기로 업로드하면 커스텀 퀘스트로 등록됩니다

---

## 초기화

**초기화** 버튼을 누르면 모든 퀘스트 완료 기록과 커스텀 필터 설정이 삭제됩니다. 되돌릴 수 없으니 주의하세요.

---

## 자동 저장

모든 진행 상황은 브라우저의 로컬 스토리지에 자동으로 저장됩니다. 페이지를 새로고침하거나 다시 열어도 이전 상태가 유지됩니다.
